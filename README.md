# Study Map

A collaborative study-tracking app: a subject/topic/subtopic map with
traffic-light progress and comments, collaborative notes with resources and
math, a leaderboard, a personal schedule, and account sign-up/sign-in.

**See [DEPLOY.md](./DEPLOY.md) for how to run this locally and deploy it to
GitHub Pages** — including an important note on how storage works once this
app is running outside Claude.

## Quick start

```bash
npm install
npm run dev
```
